# Splunk Enterprise Lab

A practical hands-on project demonstrating Splunk Enterprise installation, configuration, data ingestion, and Search Processing Language (SPL) for Security Information and Event Management (SIEM).

This repository documents my learning journey through real-world Splunk exercises with screenshots, configuration steps, and practical SPL examples.

---

## Project Objectives

- Install Splunk Enterprise
- Configure Splunk on Windows
- Create and manage indexes
- Ingest log data
- Learn Search Processing Language (SPL)
- Analyze Windows Event Logs
- Create dashboards and reports
- Build practical SIEM skills
